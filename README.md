# open-public-sharemaplocation
#English
Public location sharing tool for ShareMap.
Allows users to easily send address and GPS coordinates via 
Web Share Menu (Messenger, Viber, etc.) or standard SMS text messaging.

#Tagalog
Pangkalahatang libreng gamit para sa mabilisang pag-share ng lokasyon at address. Pumili kung isesend via Messenger/Viber (Online Apps) o irekta sa Text/SMS gamit ang iyong Phonebook.
